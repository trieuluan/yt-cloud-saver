Install Chrome Extension
  1. Click Open Extension Folder below.
  2. Click Open chrome://extensions and turn on Developer mode (top right).
  3. Drag & drop the extension folder onto the Chrome Extensions page (or click Load unpacked).
  4. Open any YouTube video and click Save to Cloud!
